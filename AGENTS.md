## Commands

| Command | What it does |
| --- | --- |
| `pnpm dev` | Dev server at https://localhost:3111 (mkcert HTTPS, Vite) |
| `pnpm dev:serve` | Start dev server as background daemon (log `.dev/dev.log`) |
| `pnpm dev:stop` | Stop the background dev daemon and rotate logs |
| `pnpm build` | Production build |
| `pnpm start` | Serve the production build on port 4000 |
| `pnpm lint` | Biome check (lint + format + organize imports) |
| `pnpm format` | Biome format --write |

**Always run `pnpm lint` after changes.**

## Conventions

- 100% client-side, offline-first: no runtime network dependency, no CDN resources, no server-rendered features.
- Package manager is pnpm (pinned via `packageManager`). Never mix npm/yarn/bun.
- Path alias `@/*` → `./src/*`; no deep relative imports.
- Routing is TanStack Router (file-based). Routes live in `src/routes/`; `src/routeTree.gen.ts` is generated by the plugin — never edit it by hand.
- Tailwind v4 syntax (`@import "tailwindcss"`, `@theme inline`) — not v3.
- Biome handles lint + format; spaces, width 2, double quotes, semicolons, import organization on.
- All user-facing strings go through `t("key")`; every key must exist in BOTH `src/i18n/locales/en.json` and `src/i18n/locales/zh.json`.
- Conventional-commit titles + detailed body; fix commits include cause + fix. Never commit unless asked; "generate git msg" prints a message, never commits.
- Never commit secrets. The mkcert dev cert (`mkcert/localhost+3*.pem`) is the only private key allowed in the repo; keep the mkcert CA out. It covers `localhost`, `127.0.0.1`, `::1`, and the LAN IP; regenerate with mkcert when the LAN IP changes. `vite.config.ts` binds the dev server on all interfaces (`server.host: true`) and reuses the same certs so `vite preview` (port 4000) also serves HTTPS; the certs are optional so a CI `vite build` works without them.
- `@rod2ik/tikzjax` runtime assets are vendored into gitignored `public/tikzjax` by both the `postinstall` script and the `build` command (install-time lifecycle hooks are skipped on cached CI installs, so the build must regenerate them itself); never reference a CDN for them. Vite must serve the vendored `*.gz` files raw — a config middleware strips the automatic `Content-Encoding: gzip`, otherwise the browser inflates them and TikZJax's own gunzip fails.
- Bundled `SKILL.md` files are imported with Vite's `?raw` suffix.
